계산의 근거: X 공개 Rust 코드 ↗

이 실험에서 바꾸는 것

  1. 같은 글을 준비해요. TweetEval에 공개된 실제 과거 트위터 글에서 중복 없이 1만 개를 뽑았습니다.
  2. 반응 예상값을 고정해요. X의 학습 모델은 제공되지 않아, 글 길이·일부 단어·고정 난수로 실험값을 만듭니다. 실제 Phoenix의 예측이나 좋아요 수가 아닙니다.
  3. 중요도를 바꿔요. ‘좋아요가 얼마나 중요한가?’ 같은 가중치만 바꿉니다. 각 예상값에 가중치를 곱하고 합치는 계산은 공개 코드에서 옮겼습니다.
  4. 결과를 비교해요. 바뀐 순위와 점수의 구성 요소를 봅니다. 같은 입력·같은 설정이면 같은 결과가 나옵니다.

실제인 것과 실험으로 채운 것

실제 자료전처리된 과거 게시글 본문, X 공개 계산식과 기본 가중치
실험용 입력반응 예상값, 작성자 그룹, 팔로우·맞팔, 관심사
없는 자료원 작성자·날짜·실제 반응 수·사진·영상·실제 Phoenix 예측값

작성자를 복원한 것이 아닙니다. ‘그룹 123’은 다양성 계산을 체험하기 위한 가상 묶음입니다. 없는 사진이나 수치를 실제처럼 붙이지 않습니다.

공개 코드 중 어디까지 실행하나요?

30개 가중 합산 항목, 맞팔 조건, 영상 조건, 음수 점수 변환, 작성자 다양성, 팔로우 밖 배율, 상위 점수 정렬을 JavaScript로 이식했습니다. 별도 모델 추론·후보 검색·Thompson Sampling·광고 혼합·운영 필터 전체는 실행하지 않습니다. ‘읽음 제외’는 수업용 필터이며 X의 Bloom filter 구현 전체가 아닙니다.

영상 지속 시청 관련 3개 가중치는 이 실험에서 0으로 시작합니다. 나머지 27개는 공개 param.rs의 기본값입니다. 데이터에 영상 정보가 없어 영상 입력도 0입니다. 체류 시간은 실험용 초 단위 값입니다.

연구 방법: 화면의 최종 결과만 보고 알고리즘을 거꾸로 추측하는 연구가 아닙니다. 공개 코드의 규칙을 먼저 읽고, 그 규칙의 일부를 통제된 입력으로 실행해 보는 실험입니다. 실제 X 피드의 편향·중독·양극화를 입증하지는 않습니다.

REA로 확인한 범위

REA 6.8.0으로 브라우저를 연결했습니다. X 공개 페이지는 HTTP 403으로 내용 관찰이 막혔습니다. 따라서 이 화면은 X 형식의 교육용 모형이며, 현재 앱 화면과 픽셀 단위로 같다고 검증한 결과는 아닙니다.
