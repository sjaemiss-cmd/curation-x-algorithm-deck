# X 큐레이션 실험실

실제 과거 트위터 글 10,000개로 가중치를 조절하는 교육용 체험 앱입니다. 공식 X 서비스가 아닙니다.

## 이용 방법
가중치 슬라이더 또는 JSON 코드를 변경하면 같은 후보의 순위를 다시 계산합니다. 글 아래 ‘왜 이 순위일까?’에서 30개 점수 항목을 확인하세요. 모바일에서는 ‘가중치 조절’ 패널을 사용하세요. 변경은 각자의 브라우저 안에서만 적용됩니다.

## 자료와 한계
- 게시글 본문: Cardiff NLP TweetEval sentiment train. 커밋 4fbd22cd78421f05b1ecdb4fc5725bc7a7bd8f66. 중복 제거 후 seed 411로 10,000개를 선택했습니다.
- https://github.com/cardiffnlp/tweeteval
- https://aclanthology.org/2020.findings-emnlp.148/
- https://aclanthology.org/S17-2088/
- 원 작성자, 날짜, 사진·영상, 실제 반응 수는 포함되지 않습니다.
- 예측값·작성자 그룹·팔로우·맞팔은 실험값입니다. 실제 Phoenix 추론을 실행한 결과가 아닙니다.
- 점수 계산은 xai-org/x-algorithm b5089266c0fbad66f388051f8f89056e2a8f974d의 일부를 JavaScript로 이식했습니다. 27개 기본 가중치를 공개 param.rs에서 추출했고, 나머지 시간 관련 3개는 0으로 시작합니다.
- 원 코드와 Apache 라이선스: evidence/ 폴더.
- REA의 X 페이지 관찰은 HTTP 403으로 막혔습니다. 현재 X 화면과 픽셀 단위 동일성을 검증한 모형은 아닙니다.
- 후보 검색·운영 모델·Thompson Sampling·전체 필터·광고 혼합은 재현하지 않습니다.

## 검증
계산·입력·데이터 테스트 8개 및 브라우저 기능 검사 17개 통과. 데스크톱·모바일과 단일 HTML 실행 확인. 실제 운영 X 피드 재현이나 인과효과 증명은 아닙니다.
